Kubernetes scheduling / field guide

How a GPU Pod
finds its node

A GPU Pod needs a node with the right GPU. Its device plugin tells Kubernetes which nodes have one.[1] The scheduler checks the Pod’s rules and picks a node; then that node’s kubelet, its local helper, connects the GPU to the container.[5][1]

The handoff
Scheduler picks a node.
Kubelet connects the GPU.[5][1]

A label is a tag. nodeSelector says “only choose a node with this tag.” A taint is a “keep out” sign; a matching toleration gives the Pod permission to enter, but does not save a GPU.[3][4] For GPUs, limits is the ask; if requests is also set, both values must match.[2]
